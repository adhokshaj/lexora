Lexora 2.0 upgrade kit
Run bash upgrade.sh from this directory. This downloads Princeton WordNet 3.0 via NLTK, generates dictionary.js and copies the complete WordNet license, then updates the existing GitHub repository. No paid dependencies. Python 3, Git and authenticated GitHub CLI required. Build stops on missing or incomplete dictionary. No dictionary.js is bundled because network download is unavailable in the build environment. Existing lexora-v1 localStorage key retained; export backup before updating. Cache version changes to v2. WordNet is not a modern slang dictionary or a CEFR assessment; existing starter entries provide additional slang. Examples and antonyms only where present in WordNet. Topic lists are generated from WordNet lexical groups, not individually curated. Difficulty is a heuristic using tagged sense counts. The generated full database can consume considerable device memory/storage. Physical iOS offline testing is still required.
