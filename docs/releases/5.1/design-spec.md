# Lexora 5.1 design specification

The visual direction stays editorial and quiet: warm neutral surfaces, slate text, restrained indigo actions, compact typography, and no chat bubbles.

## Inline words

Known words use normal text color and a subtle dotted underline. Hover and keyboard focus strengthen the underline; focus also receives the existing accessible focus ring. Controls, links, form fields, navigation, code, and existing actions are never transformed.

## Collection composer

The top of Lists contains one focused prompt field and a primary “Curate collection” action. Supporting copy explains that the prompt is sent to the configured tutor and external vocabulary sources. Loading, errors, cached responses, source links, and successful results are visible. Results appear as a preview card with suggested and locally available counts; “Save collection” is the only persistence action.

## Notes

The word page uses a labeled textarea. “Save note” is disabled until the draft differs from the stored note. A polite live status reports Unsaved changes, Saved, Note removed, or failure. Command/Control + Enter saves.
